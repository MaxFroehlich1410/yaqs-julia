ROOT CAUSE IDENTIFIED
═════════════════════

The u(θ,φ,λ) gate decomposition had φ and λ in the WRONG ORDER for
PauliPropagation's circuit time-ordering convention.

  WRONG (old code):
    Circuit list: [Rz(φ), Ry(θ), Rz(λ)]
    PP interprets first element as first gate applied in time
    This produces: Rz(λ) · Ry(θ) · Rz(φ) |ψ⟩  ← INCORRECT

  CORRECT (fixed code):
    Circuit list: [Rz(λ), Ry(θ), Rz(φ)]
    This produces: Rz(φ) · Ry(θ) · Rz(λ) |ψ⟩  ← CORRECT = Qiskit U(θ,φ,λ)

The error was invisible for:
  - Single-qubit <Z> expectations (Z commutes with Rz, so Z is insensitive
    to the Rz ordering on single qubits starting from |0⟩)
  - Qubits with only X gates (φ=λ=0, so the swap has no effect)

The error was visible for:
  - Multi-qubit states after CX entanglement (the relative phase from the
    swapped Rz matters once another qubit observes it through CNOT)
  - This is why only "active" (CX-involved) qubits showed discrepancies

ANSWERS TO THE FOUR QUESTIONS
═════════════════════════════

1. Does PauliPropagation agree with TEBD on the same 4q and 6q circuits?

   4q: YES — MAE = 2.87e-12 (machine precision) after the fix.
   6q: TEBD is unreliable at bond dim 512 (fidelity 0.0003). PP is exact
       and matches the reference much better (MAE 0.015 vs TEBD's 0.15).

2. Is the gate mapping definitely correct?

   YES — after fixing the φ/λ ordering. Confirmed by:
   - PP vs TEBD agreement at 1e-12 on 4q (72-qubit, 197 gates)
   - PP = Qiskit statevector on all tiny tests (u, cx, u+cx, Bell)
   - PP <X>, <Y>, <Z> all match Qiskit exactly for u(1.2, 0.5, 0.8)

3. Is the .npz target <Z_i> reconstruction using the correct bit convention?

   YES — Qiskit big-endian (leftmost bit = highest qubit index).
   This is confirmed by:
   - Qiskit convention gives MAE ~1.5% for both circuits
   - Native convention gives MAE >1.3 (nearly random)
   - The qiskit convention errors are consistent with the fidelity bound

4. What is the most likely reason for the huge active-qubit discrepancies?

   FOUND AND FIXED: The u(θ,φ,λ) → Rz·Ry·Rz decomposition had φ and λ
   swapped in the PauliPropagation circuit list. The PP convention is
   "first element = first gate applied in time", and U = Rz(φ)·Ry(θ)·Rz(λ)
   means Rz(λ) is applied first. The old code put Rz(φ) first.
