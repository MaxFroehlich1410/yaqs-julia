# 127-Qubit Simulation Data

This folder contains the data artifacts for
`PaperExps/scripts/ibm127_exp.jl`.

The experiment is the IBM 127-qubit kicked-Ising simulation. The data folder
contains CSV exports for standard runs as well as aggregate and per-batch pickle
outputs for the comparison plots.

## Contents

- `data/`: serialized IBM 127-qubit simulation data and CSV exports.
- `plots/`: projector-vs-standard and aggregate comparison PNGs.
